# 🥷 카페 닌자 (Cafe Ninja)

> **PlayWait W3** — 세 번째 게임 / 첫 액션 게임
> **기술**: MediaPipe Hands (검지 끝 궤적 + 선분-원 충돌)
> **난이도**: ⭐⭐⭐
> **상태**: 코드 구현 완료, 단위 테스트 105/105 통과 (실기 테스트 대기)

---

## 📌 한 줄 소개

화면 아래에서 던져지는 **카페 메뉴**를 검지 끝으로 베는 액션 게임. 60초 안에 목표 점수 도달 시 승리, **폭탄을 베면 생명 -1**.

## 🎮 게임 규칙

- 1~3개씩 동시에 메뉴 객체가 포물선으로 던져짐
- 검지 끝(landmark 8) 궤적이 객체 영역(선분-원 거리 ≤ 반지름)을 통과하면 **슬라이스 성공**
- 한 스와이프로 **여러 개 동시 베기 → 콤보 보너스**
- 종료: 목표 점수 도달(승) / 생명 0(패) / 60초 초과(패)

### 객체와 점수

| 객체 | 점수 | 등장 빈도 |
|---|---|---|
| ☕ 아메리카노 | +10 | 35% |
| 🥛 라떼 | +15 | 25% |
| ☕ 카푸치노 | +20 | 15% |
| 🍰 케이크 | +25 | 10% (큰 sprite) |
| 🥐 크루아상 | +25 | 15% |
| 💣 폭탄 | **생명 -1** | 난이도별 3~8% |

### 콤보 배수

| 동시 슬라이스 | 배수 |
|---|---|
| 1개 | ×1.0 |
| 2개 | ×1.5 (COMBO!) |
| 3개 | ×2.0 (GREAT COMBO!) |
| 4개+ | ×3.0 (WONDER COMBO!) |

폭탄은 콤보 카운트에 포함되지 않음 (메뉴만 카운트).

### 난이도

| 난이도 | 목표 점수 | spawn 간격 | 폭탄 비율 |
|---|---|---|---|
| Easy | 200점 | 1.2초 | 3% |
| Normal ⭐ | 300점 | 0.9초 | 5% |
| Hard | 450점 | 0.6초 | 8% |

## 🔄 페이즈

```
DIFFICULTY_SELECT → READY → PLAYING → GAME_OVER
                              ↻ (60초간 실시간 시뮬레이션)
```

PLAYING 한 프레임:
1. 검지 끝 좌표 추출 + 트레일 push
2. spawner가 dt 누적 후 객체 spawn
3. 모든 객체 step (포물선 운동)
4. 트레일이 **슬라이싱 중**(속도 ≥ 25 px/frame)이면 충돌 판정
5. 베인 객체에 score 적용 + 사운드 + 시각 효과 + 마킹 후 제거
6. 종료 조건 체크

## 🎨 디자인 (W1·W2 표준 유지)

- 카메라 640×480, `DISPLAY_SCALE=1.5`로 960×720 표시
- 검지 트레일: 그라데이션(과거 회색 → 최신 핑크), 슬라이싱 중 굵어짐
- 객체: 색상 원 + 영문 라벨 — sprite PNG로 추후 교체 가능
- 폭탄: 빨강 + 검정 테두리 + X 표시
- 콤보 팝업: ×1.5 핑크 / ×2.0 노랑 / ×3.0 빨강 ("WONDER COMBO!")
- 생명: ♥/♡ 문자 (NanumGothic 기본 지원)

## 📝 W2 → W3 변경 핵심

| 항목 | W2 (스피드 카운터) | W3 (카페 닌자) |
|---|---|---|
| 입력 | 양손 손가락 합산 | 한 손 검지 끝 궤적 |
| 진행 | 라운드 기반 (출제) | 실시간 시뮬레이션 |
| 안정화 | StabilityBuffer 5/4 | **없음** (액션 게임은 즉시 반응) |
| 충돌/판정 | 정수 합계 동등 비교 | 점-선분 거리 ≤ 반지름 |
| 게임오버 사유 | 5연승 / 60s / 5오답 | 목표 점수 / 60s / 생명 0 |
| 객체 동시성 | 1개 (출제 숫자) | 다수 (1~3개 동시 + 콤보) |
