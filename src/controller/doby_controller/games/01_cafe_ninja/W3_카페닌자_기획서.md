## 📌 게임 개요

**과일 닌자 스타일의 카페 메뉴 슬라이스 액션 게임.** 화면 아래에서 위로 던져지는 카페 메뉴 아이템을 손가락 궤적으로 베어내고, 폭탄(쓰레기)은 피한다. 60초 동안 목표 점수에 도달하면 승리.

### 핵심 가치 (B2B2C 관점)

| 이해관계자 | 효과 |
|---|---|
| **손님 (C)** | 짧고 강렬한 액션 — 대기시간을 즐겁게 보냄 |
| **매장 (B)** | **메뉴 노출 효과 직접 연결** — 게임 안에서 매장의 실제 메뉴 sprite가 화면을 채움. 대기하는 동안 손님이 자기도 모르게 "아메리카노 — 라떼 — 케이크" 시각 학습 |
| **플랫폼 (B)** | YOLO 보너스 미션으로 **실제 컵 인식** → 매장 머그컵 사용 손님에 추가 보상 → 친환경 캠페인/리유저블 컵 확산 데이터 |

### 핵심 특징

- **검지 끝 궤적 슬라이싱**: 손가락 끝(MediaPipe landmark 8)이 객체 영역을 빠르게 가로지르면 베기 성공
- **메뉴 5종 + 폭탄 1종**: 아메리카노 · 라떼 · 카푸치노 · 케이크 · 크루아상 · (폭탄=쓰레기 컵)
- **콤보 시스템**: 한 스와이프로 여러 객체 동시 베기 → 콤보 × 점수
- **60초 한 판**: 목표 점수(난이도별) 도달 = 승리, 실패 = 폭탄 3회/시간 초과
- **(Stretch) YOLO 보너스 미션**: 라운드 중간 "실제 컵을 보여주세요!" → 카메라에 컵을 비추면 +50점

## 🛠️ 기술 설계

### 1) 검지 끝 추적 + 스와이프 detection (W3 핵심)

```python
# MediaPipe Hands landmark 8 = 검지 끝
INDEX_TIP = 8

def get_index_tip_pixel(landmark, frame_w, frame_h):
    return (int(landmark[INDEX_TIP].x * frame_w),
            int(landmark[INDEX_TIP].y * frame_h))
```

**FingerTrail 클래스**:
- 최근 N(=10) 프레임의 검지 끝 좌표 deque
- 프레임 간 거리(픽셀)로 **속도(px/frame)** 계산
- `speed > SLICE_THRESHOLD`(예: 25px/frame ≈ 750px/s @ 30fps)일 때 "슬라이싱 중" 상태
- 시각화: 트레일 그라데이션 (최신=핑크 진함, 과거=투명)

**충돌 판정 (선분 vs 원)**:
- 직전 프레임 → 현재 프레임 검지 끝 = 선분 P1→P2
- 객체 = 중심 (cx, cy) + 반지름 r
- `point_to_segment_distance((cx,cy), P1, P2) <= r` → 슬라이스 성공

### 2) 떨어지는 객체 시뮬레이션

**FallingObject 클래스** (포물선 운동):
```python
self.x = x0
self.y = y0          # 시작은 화면 하단 밖
self.vx = vx0        # 좌우 약간의 초기 속도
self.vy = vy0        # 위로 솟구치는 초기 속도 (음수)
self.gravity = 0.5   # 매 프레임 vy += gravity
self.angular_vel = ω # 회전 (시각 효과)
```

매 프레임:
- `vy += gravity`
- `x += vx; y += vy`
- 화면 위로 안 사라지면 떨어짐 → 화면 밑으로 나가면 제거

### 3) 객체 스포너

```python
class Spawner:
    def __init__(self, difficulty):
        self.interval = SPAWN_INTERVAL[difficulty]
        self.bomb_ratio = BOMB_RATIO[difficulty]
        ...
    
    def update(self, dt) -> list[FallingObject]:
        """매 프레임 호출, 새로 spawn된 객체 리스트 반환"""
```

**spawn 다양성**:
- 단일 객체 또는 2~3개 동시 (콤보 유도)
- 화면 폭의 중앙 ±200px 범위에서 랜덤 x

### 4) YOLO 보너스 (Stretch — 1주 일정상 선택)

- 라운드 시작 30초 시점 1회 트리거
- 5초 카운트다운 동안 `ultralytics.YOLO("yolov8n.pt")`로 `cup`, `bottle` 클래스 detection
- 발견 시 +50점 보너스
- **FPS 영향 측정 후 도입**: YOLO 추론은 30fps의 ~50% 비용. 게임 중 매 프레임 X, 보너스 미션 5초 동안만 활성화하여 영향 최소화
