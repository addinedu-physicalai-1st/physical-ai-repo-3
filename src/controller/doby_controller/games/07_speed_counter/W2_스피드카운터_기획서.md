## 📌 게임 개요

화면에 등장하는 숫자(1~10)를 **두 손 손가락**으로 빠르게 표현하는 콤보 게임. 정답을 맞힐수록 제한시간이 짧아지며, **5연속 정답 도달 시 승리**.

### 핵심 특징
- **두 손 합산** 으로 1~10 표현 (예: 7 = 5 + 2)
- **가속 시스템**: 콤보가 쌓일수록 시간 단축 (3초 → 1.2초)
- **콤보 게임**: 한 번 틀리면 콤보 리셋
- **짧고 강렬**: 평균 13~15초로 5연속 도달 가능

---

## 🎮 게임 규칙

### 숫자 표현 방법

**두 손 손가락 합산**: 양손을 모두 카메라에 보여주고, 펴진 손가락 개수의 합으로 숫자 표현.

| 숫자 | 표현 예시 |
|------|----------|
| 1 | 한 손 1개 |
| 2 | 한 손 2개 또는 양손 1+1 |
| 5 | 한 손 5개 (전부 펴기) |
| 7 | 5 + 2 또는 4 + 3 |
| 10 | 양손 5 + 5 (전부 펴기) |

**중요**: 정확한 손 모양보다 **합계만** 맞으면 정답. 표현 자유도 높음.

### 게임 진행

```
[게임 시작]
   ↓
[난이도 선택]
   ↓
[라운드 시작 - 콤보 0]
   ↓
┌─→ [숫자 출제 (1~10 랜덤)]
│       ↓
│  [3초 카운트다운 (또는 가속)]
│       ↓
│  [손가락 안정 평가 (1초)]
│       ↓
│  [정답 판정]
│   ├─ 정답 → 콤보 +1, 다음 문제
│   └─ 오답/시간초과 → 콤보 리셋, 오답 카운트 +1
│
└─< [5연속 도달?]  → YES → 🏆 승리
    [60초 초과?]   → YES → 😢 패배
    [오답 5회?]    → YES → 😢 패배
```

### 가속 시스템 (시간 단축)

콤보에 따라 답 확정 시간이 단축됩니다.

| 콤보 | 제한 시간 | 비고 |
|------|----------|------|
| 0~2 | **3.0초** | 워밍업 |
| 3~4 | **2.5초** | 가속 시작 |
| 5+ | **2.0초** | 즉시 승리 |

**참고**: 5연속 시 즉시 게임 종료라 5콤보 이후 시간은 사실상 사용 X. 디자인적으로는 더 어려운 변형 모드(10콤보 이상)에 활용 가능.

### 손 안정성 평가

답 확정은 다음 조건이 모두 만족되어야 함.

1. **합계가 출제 숫자와 일치**
2. **0.5초 이상 같은 합계 유지** (안정 평가)

흔들림이 심하면 안정 평가 통과 못 함 → 다시 시도.

- **누적 오답 5회** → 너무 많은 실수

### 가속 시간 결정

```python
def get_time_limit(combo: int, difficulty: str) -> float:
    """콤보와 난이도에 따른 제한 시간"""
    base = {
        "easy": 4.0,
        "normal": 3.0,
        "hard": 2.0,
    }[difficulty]
    
    if combo < 3:
        return base
    elif combo < 5:
        return base * 0.83  # 약 -0.5초
    else:
        return base * 0.67  # 약 -1.0초
```
